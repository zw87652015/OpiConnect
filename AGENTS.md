# OpiConnect

Android notifications mirrored to Apple Watch. `docs/PROTOCOL.md` is the authoritative
spec for crypto, pairing, BLE, and the relay API; `docs/test-vectors.json` covers every
implementation (generated by `docs/gen-test-vectors.mjs`).

## Layout

- `watch/` — watchOS app (Xcode 16+ project, synchronized folders): `OpiConnect`
  watchapp2-container, `OpiConnect Watch App`, `NotificationService` (NSE), `Shared`
  (compiled into app + NSE), `OpiConnectTests`. Shared schemes: "OpiConnect Watch App"
  (run/test), "OpiConnect" (archive). `Local.xcconfig` is git-ignored (DEVELOPMENT_TEAM,
  BUNDLE_PREFIX).
- `android/` — Kotlin + Compose app; `core/` is pure Kotlin (JVM-unit-testable).
- `server/` — Node 22 single-file APNs relay (`index.mjs`) + `test.mjs` + deploy README.

## Verify

- Watch (on this Mac, Xcode 27):
  `xcodebuild test -project watch/OpiConnect.xcodeproj -scheme "OpiConnect Watch App" -destination 'platform=watchOS Simulator,name=<watch sim>' CODE_SIGNING_ALLOWED=NO`
  and `xcodebuild build -project watch/OpiConnect.xcodeproj -scheme "OpiConnect" -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO` (confirms the container embeds the watch app + NSE).
- TestFlight: `scripts/testflight.sh` archives the "OpiConnect" container and uploads it
  (`DESTINATION=export` for a local .ipa only). The container target must keep
  `SKIP_INSTALL = NO`, otherwise the archive's Products folder is empty.
- Server: `node --check server/index.mjs && node --test server/test.mjs`
- Android: built on the user's Windows machine — `gradlew :app:assembleDebug :app:testDebugUnitTest`.
  This Mac only has JDK 11; do not try to run AGP here.

## Protocol changes

Any change to crypto/pairing/BLE/relay semantics must update `docs/PROTOCOL.md`,
regenerate vectors (`node docs/gen-test-vectors.mjs`), and keep the Swift and Kotlin
vector tests passing on both platforms.
